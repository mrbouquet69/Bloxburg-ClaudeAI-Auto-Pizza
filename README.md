# Let Claude play the Bloxburg pizza job: setup guide

Claude plays the job itself by looking at your screen and clicking. It does not run a bot or script.

**Account warning:** automating Roblox can break Roblox's rules and put your account at risk. Use at your own risk.

## What you need
- A Windows PC with Roblox installed.
- The Claude desktop app installed and signed in on that PC.
- Computer use turned on: Claude desktop app > Settings > This computer > Computer use.

## Steps
1. Save the skill. Click Save on the "bloxburg-pizza-job" skill card in Claude. If you're sharing this with someone else, give them the `SKILL.md` text below and have them ask Claude to save it as a skill.
2. Open Roblox, join Bloxburg, and clock in at Pizza Planet as a Pizza Baker. Stand at a pizza station.
3. Close other windows that could cover the game (browser, Discord, and so on).
4. Start a chat in the Claude desktop app on that PC. Cloud projects can't control your screen. Ask something like:
   "Play the Bloxburg pizza job using the bloxburg-pizza-job skill until 11 PM. Tell me my earnings and average efficiency at the end."
5. Click Allow when Claude asks to control Roblox. If there's a second prompt for the game window (Robloxplayerbeta), allow that too.
6. Say "stop" whenever you want it to stop.

## Tips
- Keep the Roblox window maximized and don't use the mouse or keyboard while Claude plays.
- If Claude seems stuck, check whether a window is covering the game.
- When ingredients run out, Claude fetches a crate from the boxes behind the counter and restocks the station.
